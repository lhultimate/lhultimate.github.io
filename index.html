01 — Selected work

The main event

One project carries most of my hours, and it's the one I'm proudest of.

ScorePlus

Featured · Open source

Scoreboard and broadcast graphics software for live production. One operator console driving unlimited audience displays, with a scorebug you design yourself — running entirely on a single Windows PC, with no server, no browser and no internet connection.

Live values hit the audience the instant they change. Everything else is staged, so you can rehearse a change and put it on air when you decide. It ships as a self-contained executable, so there's no runtime to install and nothing to configure between soundcheck and kickoff.

02 — About

Hey — I'm LHUltimate.

I'm a programmer who likes the unglamorous half of software: the parts that have to keep working while everyone else is busy. Clocks that can't drift, files that can't be lost, a graphic that lands on the beat.

Most of what I build is C# and .NET on Windows, because that's what the hardware in the booth actually runs. I write it all myself — interface, engine, file formats, packaging — and then I give it away.
